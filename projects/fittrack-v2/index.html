Case study 03 / Mobile Application

FitTrack V2 — Workout Planner.

A mobile application for organising workouts, exploring exercises and keeping supporting fitness tools close at hand.

Contribution
Individual Developer
Technologies
Flutter · Dart
OverviewFeaturesDevelopmentGallery

01 / Context

Project overview.

I built FitTrack V2 to practise mobile application development around a familiar use case: organising a workout. The application brings planning, exercise information and supporting tools into a connected set of mobile screens.

The main use case is someone choosing exercises, planning a routine and using a timer during a workout. The screenshots also show a BMI calculator and a profile interface alongside the core planning tools.

02 / In the application

Key features.

  1. 01

    Workout planner

    A date-based schedule displays a planned routine and its recommended exercises.

  2. 02

    Exercise directory

    The directory groups exercise cards with search and category controls.

  3. 03

    Exercise details

    A detail screen shows an exercise illustration, description, difficulty and workout configuration.

  4. 04

    Workout timer

    A dedicated timer screen includes start/reset controls and quick duration presets.

  5. 05

    BMI calculator

    Height and weight controls are paired with a BMI result and supporting information.

03 / Building & learning

Development journey.

Flutter and Dart let me build the mobile screens and work through their navigation in one project. I used a repeated bottom navigation pattern to keep the main areas visible as the user moves between tools.

The work involved balancing detailed exercise information with controls that still fit comfortably on a phone.

Main challenge

Mobile UI Design & Navigation

The main challenge was connecting several workout features without making navigation feel crowded. Working on screen hierarchy, consistent controls and the placement of supporting information helped me think more carefully about mobile usability.

What I’m taking forward.
