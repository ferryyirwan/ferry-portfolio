Case study 02 / Full-Stack Web Application

Indigenous Community Marketplace.

A web marketplace for discovering indigenous community products and managing seller listings.

Contribution
Individual Developer
Technologies
Laravel · PHP · MySQL · HTML · CSS
OverviewFeaturesDevelopmentGallery

01 / Context

Project overview.

I built this marketplace to practise creating a full-stack web application with both public product pages and seller-facing tools. The aim was to make product discovery and listing management understandable within the same interface.

Visitors can browse products and read their details, while the seller interface brings listings and store information together. The screenshots are from my study project; the Turtle Conservation branding shown does not establish an official partnership or deployment.

02 / In the application

Key features.

  1. 01

    Product discovery

    A product catalogue presents images, prices, categories and seller information, with search and filter controls.

  2. 02

    Product information

    A dedicated product page gives the image and description more room, alongside price and category details.

  3. 03

    Listing management

    The seller product table includes controls for adding, viewing, editing and removing listings.

  4. 04

    Seller dashboard

    A store overview combines summary cards with a recent-orders table and links to seller tools.

03 / Building & learning

Development journey.

I used Laravel, PHP and MySQL for the application, with HTML and CSS for the pages. The work covers both the public browsing experience and the more structured layouts used by a seller.

Moving between a visual product catalogue and a dense management table made interface consistency a useful design problem to work through.

Main challenge

Frontend Interface Design

The main challenge was organising product and seller interfaces clearly. I worked on consistent spacing, product presentation and page hierarchy so the different views would feel part of the same application.

05 / Looking back

What I’m taking forward.

This project helped me connect backend functionality with the interface people actually use. I learned to pay more attention to how layout and consistent presentation make product information easier to understand.
