01 / MOBILE APPLICATION Academic Project

FitTrack V2 – Workout Planner Mobile App

A comprehensive workout planner and fitness tracking application developed with Flutter and Dart, engineered to deliver smooth cross-platform workout planning, interactive timers, BMI calculations, and personalized routine management.

Flutter Dart Android / iOS Mobile UI/UX State Management Material Design
View on GitHub ↗ View Screenshots (8) ↓

🎯 Project Objective

Developed as an academic mobile computing project at Kolej Profesional MARA Beranang to empower users with an intuitive tool for structuring workouts, tracking fitness metrics, and maintaining consistent exercise routines.

🏋️ Workout Management

Provides categorized exercise directories with step-by-step instructional guides, target muscle breakdown, and difficulty indicators to help users perform exercises safely and effectively.

⚖️ BMI & Fitness Tools

Integrated Body Mass Index (BMI) calculator with dynamic metric inputs and visual status classifications, alongside an interactive workout countdown stopwatch timer for interval sessions.

👤 Personalization & Scheduling

Features dedicated weekly workout calendar scheduling, favorites bookmarking, and personal profile management to track fitness milestones over time.

02 / FULL-STACK WEB DEVELOPMENT E-Commerce & Social Impact

Indigenous Community Marketplace

A web-based e-commerce marketplace platform developed using Laravel, PHP, and MySQL. Built to support local and indigenous artisans by facilitating the sale of eco-friendly and turtle-themed handicrafts in direct collaboration with the Turtle Conservation Society of Malaysia (TCS).

Laravel PHP MySQL Blade Templates JavaScript MVC Architecture Bootstrap / CSS
View on GitHub ↗ View Screenshots (5) ↓

🌐 Multi-Role Access Control

Implements distinct roles and security gates for Public Visitors (browsing catalog, learning conservation goals), Registered Buyers (purchasing, receipts), and Sellers (store management).

📦 Seller Inventory CRUD

Dedicated Seller Dashboard enabling complete product lifecycle management: adding items, uploading product photography, editing prices/stock, and removing obsolete merchandise.

💳 Order & Payment Workflow

Buyers place orders with custom delivery options and upload proof-of-payment bank slips. Sellers review orders and verify payment receipts in real time before fulfillment.

🗄️ Relational Database & MVC

Engineered with clean Laravel MVC design patterns and a robust MySQL schema modeling Users, Products, Orders, Order Items, and Payment Verification entities.

03 / DISTRIBUTED SYSTEMS & REAL-TIME High Availability Backend

NexaTech Notification System

A distributed, fault-tolerant real-time notification platform built with Node.js, Socket.IO, and Redis Pub/Sub. Designed for institutional lecturer-student announcements with cross-server synchronization and client-side automatic server failover.

Node.js Socket.IO Redis Pub/Sub WebSocket Distributed Architecture Server Failover
View on GitHub ↗ View Screenshots (3) ↓

⚡ Real-Time WebSocket Delivery

Leverages Socket.IO for low-latency bidirectional message dispatch, allowing lecturers to broadcast critical classroom notices instantly to all connected student clients.

🔄 Redis Pub/Sub Synchronization

Employs Redis message publishing and subscription to synchronize events across independent application instances (Server 1 and Server 2), eliminating isolated silos.

🛡️ Automatic Server Failover

Engineered with resilient client-side failover logic: if the active primary server crashes or disconnects, the client instantly reconnects to the backup server without dropping message history.

👥 Role Interaction & Presence

Features dedicated lecturer broadcast permissions, student question and acknowledgment replies, and live connected user count monitoring across both cluster nodes.

04 / DESKTOP APPLICATION & DATA Decision Support System

Weather Analytics & Forecast Decision Support

A desktop analytics and decision support application developed using Electron and modern JavaScript. Integrates live meteorological data from WeatherAPI to provide predictive forecasting, automated rain risk analysis, and weather-driven activity planning across Malaysia.

Electron JavaScript WeatherAPI HTML5 & CSS3 LocalStorage Data Visualization
View on GitHub ↗ View Screenshots (3) ↓

🇲🇾 Malaysia Multi-City Weather

Real-time API integration fetching current temperature, humidity, wind velocity, and atmospheric condition metrics for cities and states throughout Malaysia.

📅 Extended & Hourly Timelines

Comprehensive meteorological timelines displaying hourly temperature progression and 3-day extended forecasts for proactive daily scheduling.

🧠 Decision Support Engine

Algorithmic decision support calculating rain risk percentages, extreme heat warnings, and intelligent outdoor vs. indoor activity safety recommendations.

📋 Activity Planner CRUD

Full-featured personal schedule planner with LocalStorage persistence, allowing users to save, edit, and organize events aligned with forecast conditions.
